# Threestar Almanac

An autobattler. This repository holds its releases only.

**To play:** open the [latest release](https://github.com/medsrk/Almanac/releases/latest) and download the launcher for your system:

- Mac: `Threestar-Almanac-mac.zip`
- Windows: `Threestar-Almanac-windows.zip`

The launcher installs the game and keeps it up to date every time you open it.
